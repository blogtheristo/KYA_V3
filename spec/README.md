# KYA v3 specification

KYA v3 is a release name over versioned components. The open part is **KYA-S1**, the attestation
specification: seven control domains (identity, behaviour, registration, halt, fleet, trust,
provenance) and assurance levels KYA-AL1 to KYA-AL3.

**Publication state (09.10.2026):** the KYA-S1 text is not yet in this repository. It will be
added here, under Apache-2.0, once Lifetime Oy approves the public version. Until then, ask for it
at risto.paarni@lifetime.fi.

What will not be published here: the enforcement engine (Themis), deployment constraints (Capacity
Class) and the evidence chain (Aegis). See the main README.
